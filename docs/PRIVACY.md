# Политика конфиденциальности ФинПет

Действует для версии 0.1.0 и далее, пока не изменится этот документ.

**ФинПет не собирает, не передаёт и не продаёт никакие данные.**

- **Какие данные есть.** Приложение хранит имя питомца, имя, которое ввёл ребёнок, и игровой прогресс: монеты, покупки, уроки, дни. Всё это лежит в локальной базе SQLite на устройстве.
- **Куда уходят данные.** Никуда. Приложение не выходит в интернет, в нём нет аналитики, рекламы, SDK третьих сторон и учётных записей.
- **Разрешения Android.** Не запрашиваются (`android.permissions: []`).
- **Покупки.** Реальных платежей нет, все деньги в игре — игровые монеты.
- **Удаление данных.** «Для взрослых» → «Сбросить прогресс» обнуляет игру. Удаление приложения стирает всё, включая имена.
- **Дети.** Приложение рассчитано на детей 7–11 лет. Взрослый раздел закрыт вопросом-гейтом.

Вопросы: команда hsespbteam, через issues репозитория проекта.
