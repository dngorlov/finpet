# Как добавить урок (без кода)

Все уроки и мини-игры — это данные в `assets/content/tasks.json`. Код трогать не нужно: загрузчик проверит файл при запуске и тестах (`npm test`) и назовёт ошибку.

## Заменить «скоро» на настоящий урок

На карте уже стоят три точки `budget_3`, `savings_3`, `payments_3` с `"comingSoon": true`. Чтобы урок появился:

1. Уберите `"comingSoon": true`.
2. Заполните `title`, `description`, `intro`, `difficulty` (1–3) и `reward` (максимум монет, обычно 10 или 15).
3. Замените `nodes` на карточки и игру (см. ниже).

Урок сам встанет в цепочку темы по `order` и откроется после предыдущего.

## Новая точка на карте

Скопируйте урок, дайте новый `id`, `order` = следующий номер в теме и `pin`: `x`, `y` — доли картинки карты (0 — левый/верхний край, 1 — правый/нижний), `district` — название района.

## Шаги урока (`nodes`)

Первый шаг — первый в списке. Каждый шаг говорит, куда идти дальше (`next`: id шага или `"exit"` — конец урока).

- **Карточка** — теория, не оценивается:
  `{ "id": "c1", "kind": "card", "title": "Что такое бюджет?", "text": "…", "next": "c2" }`
  На последней карточке можно написать кнопку: `"button": "Начать игру"`.
- **Вопрос** — оценивается первый ответ:
  `{ "id": "q1", "text": "Вопрос?", "options": [ { "label": "Ответ", "next": "q2", "verdict": "good", "explanation": "Почему верно" }, { "label": "Ответ", "next": "retry", "verdict": "bad", "explanation": "Почему нет" } ] }`
  `verdict`: `good` — верно, `warn` — можно, но с ценой (½ балла), `bad` — неверно. `"next": "retry"` — попробовать этот же вопрос ещё раз.
- **Сортировка** («Нужно или хочется?»):
  `{ "id": "g1", "kind": "sort", "text": "Нужно или хочется?", "bins": ["Нужно", "Хочется"], "items": [ { "label": "Обед", "bin": 0, "explanation": "…" } ], "next": "exit" }`
  `bin` — номер корзины с нуля. Каждый предмет — один балл.

`{pet}` в любом тексте заменится на имя питомца ребёнка.

## Мини-игра внутри урока

Отдельное задание с `"parent": "<id урока>"` и без `pin`/`order` — появится кнопкой в карточке этого урока после его прохождения.

## Награда

Монеты = `reward` × доля верных с первого раза ответов. Повтор доплачивает только разницу с лучшим результатом.
